# Наша встреча ❤️ (24.09.2026 06:42 — 30.09.2026 21:42)

Романтический веб-сайт встречи с любимой девушкой: таймер приезда и отъезда, интерактивная фотогалерея и нежные сюрпризы.

## 🌟 Возможности

- **Таймер встречи:** зафиксирован на дате приезда (24 сентября 2026 в 06:42 МСК) с возможностью переключения на дату отъезда (30 сентября 2026 в 21:42 МСК).
- **Интерактивная фотогалерея 📸:**
  - Просмотр фото на весь экран (Lightbox) с увеличением и листанием стрелками.
  - Загрузка фотографий прямо на сайте (с телефона или ПК) — сохраняются в памяти браузера (`IndexedDB`).
  - Возможность добавить общие фото навсегда для всех устройств: просто положить файлы в папку `assets/gallery/`.
- **Совместная фотография** в стиле полароида со свечением.
- **Интерактивное любовное письмо 💌** (открывающийся конверт с нежным признанием).
- **Кнопка «Отправить поцелуй» 💋** со взрывом сердечек и счетчиком поцелуев.
- **Романтическая фоновая музыка 🎵** (встроенный Web Audio синтезатор без внешних зависимостей).
- **Планы на дни встречи** (интерактивный чеклист).
- **Анимированный фон** с парящими звездами и сердечками на Canvas.
- **100% адаптивность** под смартфоны и компьютеры.

## 🚀 Деплой на Vercel

### Вариант 1: Через GitHub (рекомендуется)
1. Запушьте этот репозиторий на GitHub:
   ```bash
   git add .
   git commit -m "feat: romantic countdown site"
   git push origin main
   ```
2. Откройте [vercel.com](https://vercel.com) и нажмите **"Add New..." -> "Project"**.
3. Выберите ваш репозиторий `mm` и нажмите **"Deploy"**.
4. Сайт будет готов через 10 секунд и получит красивую ссылку (например, `mm-six.vercel.app`), которую можно отправить любимой!

### Вариант 2: Через Vercel CLI
```bash
npx vercel
```
